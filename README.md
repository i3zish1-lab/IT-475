Lincoln Middle School — Practice Dataset 

This is an independent practice dataset for learning the Excel + Orange
SPSS workflow. It uses different student counts, names, and a different natural
distribution across risk tiers than the first practice set, so you can rehearse
the same pipeline on fresh numbers.

Structure:
- 35 fictional students (LMS-201 .. LMS-235)
- Organic (non-quota) distribution: 7 dual-risk, 6 academic-only, 8 attendance-only, 14 satisfactory

Thresholds (same rule definitions as the assignment):
- Academic Threshold: Average of Test 1-3 < 60% => FAIL
- Attendance Threshold: Attendance % < 75% => FAIL

Columns F (Average), H (Academic Status), I (Attendance Status), and J (Risk Category)
are LIVE FORMULAS and recalculate automatically if you edit C:E or G.

The Dashboard tab uses a different KPI/chart layout than practice set #1:
donut chart, a horizontal 'Watch List' bar of the 8 lowest-attendance students,
and a stacked-column weekly trend instead of a line chart.
